# Analysis artifacts

The analysis tree contains the currently available scripts and derived tables
for:

- manifest profiling and missing-cell matrices;
- binary success summaries and Wilson confidence intervals;
- qualitative failure-mode annotation and review;
- per-model and per-task failure profiles;
- paired same-scene comparisons with bootstrap intervals;
- final figure generation.

Historical scripts may contain absolute paths to their original workbooks.
These should be replaced with command-line arguments during the publication
cleanup, without altering the archived source spreadsheets.
