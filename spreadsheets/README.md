# Spreadsheet archive

`working_archive/` contains the currently available `.xlsx` and `.csv` files
used while constructing the fine-tuning manifest, evaluation plans, consolidated
results, failure analyses, and thesis figures.

The archive preserves the source directory names and should be treated as a
working research record, not yet as the final public spreadsheet release.
Files copied from generated dataset mirrors and Excel lock files are excluded.

Before archival release:

1. identify canonical workbooks and clearly label superseded revisions;
2. standardize visible naming to Spa-Bench and GR00T-N1.7 Frozen LLM;
3. remove personal metadata, local links, and unintended hidden content;
4. export important worksheets to CSV;
5. regenerate `MANIFEST.sha256`.

`MANIFEST.sha256` records the current binary snapshot and allows later edits to
be distinguished from the files assembled during this repository pass.
